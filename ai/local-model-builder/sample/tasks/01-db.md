Create `shelf/db.py` with:

- `connect(path: str) -> sqlite3.Connection`: open the SQLite file, set `row_factory = sqlite3.Row`, and run
  `PRAGMA foreign_keys = ON`.
- `init_db(conn) -> None`: create the `items` and `item_tags` tables exactly as in the spec (columns in that order),
  using `CREATE TABLE IF NOT EXISTS` so it can run more than once, and commit.
